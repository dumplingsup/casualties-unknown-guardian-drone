# 守护无人机 0.1.0（测试版）

适用：Casualties: Unknown，已核对 Steam build **26666273**。依赖 BepInEx 5（实测 5.4.23.6）与 CUCoreLib **1.1**。仅声明单人；其他游戏版本、联机和未列出的模组组合未验证。

## 安装与使用

安装依赖后，将压缩包内的 `BepInEx` 文件夹合并到游戏根目录。最终文件是：

`BepInEx/plugins/GuardianDrone/GuardianDrone.dll`

进入新局或读取旧局后，角色会免费获得一只“守护无人机控制器”；背包满时放在脚边。将控制器放在自己的背包或随身容器中。

- 使用控制器，或 **F6**：部署／收回。
- **F7**：自动护航射击／停火。停火不影响自动治疗。
- **F8**：优先处理可治疗的外伤。

无人机无敌，不消耗电池、弹药、药品或其他材料。默认在开阔处距主角约 **6–9 格**的上方弧线巡航；洞穴空间不足时会调整位置，持续卡住时收纳并重新部署。它不推挤主角。

自动锁定部分已知原版威胁（SpiderHandler 系列生物、洞穴蜱与激光无人机），暂不主动锁定未知模组 NPC。射击有飞行时间和少量散布；**弹道上的主角、旁人或其他实体都可能中弹**，墙体会吸收弹丸。想避免开火时按 F7。

## 医疗范围

严重出血时优先靠近急救，普通外伤在有威胁时可能等待战斗间隙。近距离、无遮挡时显示治疗光束，逐步止住外伤出血，修复仍存在的生物肢体的皮肤和肌肉。

本版不补充已经流失的血液，不处理骨折、脱臼、内出血、感染、毒素、缺氧、脑损伤、义肢和断肢。残留破片需要先移除。绿色光束不表示所有病因都已解决。

## 存档、机甲与配置

部署意愿和护航／停火状态通过 CUCoreLib 随角色保存。读档后在主人附近重新部署一台，不保存飞行坐标或当前敌人。正常换层仍会跟随。

可与 Wayfarer Mech 0.4.9 一起安装，不需要将机甲设为前置；驾驶时参考机甲位置巡航，暂停对隐藏驾驶员的治疗，下机后继续医疗。具体已执行的组合测试见工作区验收记录；这不代表所有第三方组合均兼容。

首次运行生成 `BepInEx/config/local.cu.guardiandrone.cfg`，可改按键、巡航距离、伤害、射击间隔和治疗速度。

卸载或换版本前备份存档。建议先收回无人机、移除随身控制器，再正常保存；含自定义物品的存档不能保证在缺少相应模组或依赖时仍可读取。

这是先跑通功能的初版。无资源系统、无人机不受损；多人、全部敌人覆盖、复杂医疗和大规模性能尚未验证。包内不含测试探针、游戏程序集或第三方美术。
