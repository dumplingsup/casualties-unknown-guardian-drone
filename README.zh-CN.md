# 守护无人机 0.2.0

适用：Casualties: Unknown，已核对 Steam build **26666273**。依赖 BepInEx 5（实测 5.4.23.6）与 CUCoreLib **1.1**。只声明单人。其他游戏版本、联机和未列出的模组组合未验证。

0.1.0 会在主角挡着弹道时继续开火，洞穴里也可能够不着伤口。那些问题留在历史包里。0.2.0 改为先看弹道，够不着落点就收起等待。验收里哪些做了、哪些没做，见 [0.2.0 验收记录](https://github.com/dumplingsup/casualties-unknown-guardian-drone/blob/main/docs/V0.2.0.md)。

## 安装与使用

安装依赖后，将压缩包内的 `BepInEx` 文件夹合并到游戏根目录。最终文件是：

`BepInEx/plugins/GuardianDrone/GuardianDrone.dll`

进入新局或读取旧局后，角色会免费获得一只「守护无人机控制器」；背包满时放在脚边。已经有控制器时不会再发一只。控制器若彻底消失，大约 3 秒后补发一只；再次读入角色或换层前最多补发一次。把它留在自己的背包里。放在地上时，无人机收回，并说明原因。

- 使用控制器，或 **F6**：部署／收回。
- **F7**：自动护航射击／停火。停火不影响自动治疗。
- **F8**：优先处理可治疗的外伤。

画面左上角用图标和两行字显示护航还是停火，以及正在巡航、换位、治疗、收起或被挡住。

无人机无敌，不消耗电池、弹药、药品或其他材料。开阔处默认距主角约 **6–9 格**。低矮洞穴改成较近的侧面位置。没有开阔格子时它收起，等周围空出来再出现，不会钻进墙里。

它按类型、距离和部分视线检查选择近处的已知威胁，可能在对方先攻击前开火，当前没有完整的敌意／仇恨识别。射击有飞行时间和少量散布。主角或旁人已经站在弹道上时，它停火并尝试换到侧翼。**已经飞出去的弹丸仍可能打中主角和旁人。** 想停火时按 F7。

## 医疗范围

严重出血、失去意识或按 F8 时会靠近处理，并一直处理到出血明显下降，不会在门槛附近马上回头射击。轻伤在有威胁时先让路。近距离、射线没被挡住、而且确实在修复时才显示绿色光束。它止住外伤出血，并修复仍存在的生物肢体的皮肤和肌肉。

本版不补充已经流失的血液，不处理骨折、脱臼、内出血、感染、毒素、缺氧、脑损伤、义肢和断肢。残留破片需要先移除。

## 存档、机甲与配置

部署意愿和护航／停火状态通过 CUCoreLib 随角色保存。读档后在主人附近重新部署一台，不保存飞行坐标或当前敌人。

可与 Wayfarer Mech 一起安装，不需要把机甲设为前置；驾驶时参考机甲位置，并暂停对隐藏驾驶员的治疗。0.2.0 这一轮没有把机甲放进隔离测试。

首次运行生成 `BepInEx/config/local.cu.guardiandrone.cfg`，可改按键、巡航距离、伤害、射击间隔、治疗速度和音量。音量为 0 时静音。

卸载或换版本前备份存档。建议先收回无人机、移除随身控制器，再正常保存。含自定义物品的存档不能保证在缺少相应模组时仍可读取。

多人、守卫、固定炮塔和未知生物没有在这一轮验证。包内不含测试探针、游戏程序集或第三方美术。

手动升级时先关闭游戏，替换旧的 `GuardianDrone.dll`，只保留一份。0.2.0 的状态框可能与左上角原版物品标签重叠。最终上架复核使用静音，未对音效听感作验收。
