# 守护无人机 0.3.0

适用：Casualties: Unknown，已核对 Steam build **26666273**。依赖 BepInEx 5（实测 5.4.23.6）与 CUCoreLib **1.1**。只声明单人。其他游戏版本、联机和未列出的模组组合未验证。

0.3.0 重做战斗／治疗优先级。F8 循环 **自动 → 防御优先 → 医疗优先**：自动模式有交战目标时先战斗，安全时治疗，总出血达到临界值才急救；防御优先以屏幕内可见威胁为界，威胁出现立即暂停治疗，画面清空并稳定后再治疗；医疗优先即使交火也先治疗。同时修复治疗锁存清空战斗目标，以及守卫、炮塔、`CrystalEnemy` 因白名单、扫描层和 `indestructible` 标志被忽略的问题。逐项实测见 [0.3.0 验收记录](https://github.com/dumplingsup/casualties-unknown-guardian-drone/blob/main/docs/V0.3.0.md)。

0.1.0 会在主角挡着弹道时继续开火，洞穴里也可能够不着伤口。那些问题留在历史包里。0.2.0 改为先看弹道，够不着落点就收起等待。0.2.1 修复随时存档类模组读档后可能多出一只控制器，以及部署状态下换层可能卡死。

## 安装与使用

安装依赖后，将压缩包内的 `BepInEx` 文件夹合并到游戏根目录。最终文件是：

`BepInEx/plugins/GuardianDrone/GuardianDrone.dll`

进入新局或读取旧局后，角色会免费获得一只「守护无人机控制器」；背包满时放在脚边。控制器在快捷栏、穿戴容器或储物箱里都算已有，不会重复发放。控制器彻底消失约 3 秒后补发一只；读档后 12 秒内不补发，让存档模组先还原整层。补发之后如果原控制器又出现，模组会移除自己补发的那只。把它留在自己的背包里。放在地上时，无人机收回，并说明原因。

- 使用控制器，或 **F6**：部署／收回。
- **F7**：自动护航射击／停火。停火不影响自动治疗。
- **F8**：循环支援优先级：**自动 → 防御优先 → 医疗优先**。

画面左上角用图标和两行字显示护航还是停火、当前优先级，以及正在巡航、防御、换位、治疗、收起或被挡住。因屏幕内有威胁而暂停治疗时，第二行会显示「暂停治疗」。

无人机无敌，不消耗电池、弹药、药品或其他材料。开阔处默认距主角约 **6–9 格**。低矮洞穴改成较近的侧面位置。没有开阔格子时它收起，等周围空出来再出现，不会钻进墙里。

它按类型、距离、交战距离和部分视线检查选择近处的已知威胁，可能在对方先攻击前开火，当前没有完整的敌意／仇恨识别。支援类型包括蜘蛛、洞穴蜱、激光无人机、守卫、炮塔、天花板炮塔和水晶敌人；商人只有在自身 `hostile` 标志进入敌对状态后才算敌人。射击有飞行时间和少量散布。主角或旁人已经站在弹道上时，它停火并尝试换到侧翼。**已经飞出去的弹丸仍可能打中主角和旁人。** 想停火时按 F7。

## 医疗范围与优先级

- **自动**：没有可交战目标时治疗；目标出现时继续战斗，目标消失约 0.75 秒后恢复治疗。总出血达到 10（可配置）时会强制急救，避免战斗中失血过多。
- **防御优先**：屏幕内出现受支持敌对实体就保持防御并暂停治疗；目标要在主角附近约 30 世界单位内、相机可见且有视线。画面清空并稳定约 1 秒后恢复治疗；治疗中威胁重新出现会立即停止。
- **医疗优先**：即使交火也先治疗，直到再按 F8 切走。

严重出血、失去意识或医疗优先时会靠近处理，并一直处理到出血明显下降。轻伤在有威胁时先让路。近距离、射线没被挡住、而且确实在修复时才显示绿色光束。它止住外伤出血，并修复仍存在的生物肢体的皮肤和肌肉。

本版不补充已经流失的血液，不处理骨折、脱臼、内出血、感染、毒素、缺氧、脑损伤、义肢和断肢。残留破片需要先移除。

## 存档、机甲与配置

部署意愿、护航／停火状态和自动／防御／医疗优先级通过 CUCoreLib 随角色保存。换层或读档时无人机自动收回，确认面板一出现就落地；等新层加载完成并稳定约 2.5 秒后再回到主人附近，不保存飞行坐标或当前敌人。0.2.1 旧存档没有优先级字段，读入后按自动处理。

已与 Save Anywhere 1.5.0 同测：控制器在快捷栏或随身容器里时，读档后仍只有一只。控制器放在地面或世界容器里时，Save Anywhere 的世界快照无法还原这种自定义物品；本模组会在 12 秒保护期后补发一只，仍然只有一只。

也已在隔离副本里与报告链接的 QoL Unknown 7 v1.1.4 同测：QoL 的深度存档会把自定义控制器还原成未激活物品；0.2.1 会找到并激活原控制器，不再补发第二只。部署状态下换层也不会再卡住。

可与 Wayfarer Mech 一起安装，不需要把机甲设为前置；驾驶时参考机甲位置，并暂停对隐藏驾驶员的治疗。0.3.0 这一轮没有把机甲放进隔离测试。

首次运行生成 `BepInEx/config/local.cu.guardiandrone.cfg`，可改按键、巡航距离、伤害、射击间隔、治疗速度、自动模式的急救出血阈值和音量。音量为 0 时静音。

卸载或换版本前备份存档。建议先收回无人机、移除随身控制器，再正常保存。含自定义物品的存档不能保证在缺少相应模组时仍可读取。

0.3.0 在隔离副本里实测了守卫、固定炮塔、天花板炮塔和水晶敌人的识别；敌对商人路径已接入但未在游戏内生成商人实测。多人、机甲同场和未列出的生物没有在这一轮验证。包内不含测试探针、游戏程序集或第三方美术。

手动升级时先关闭游戏，替换旧的 `GuardianDrone.dll`，只保留一份。状态框仍可能与左上角原版物品标签重叠，窗口较小时更明显。最终上架复核使用静音，未对音效听感作验收。
