# Guardian Drone 0.2.0 验收

日期：2026-11-15。0.1.0 的失败记录仍在 [V0.1.0.md](V0.1.0.md) 和 [PLAYABILITY-REVIEW.md](PLAYABILITY-REVIEW.md)。本文件只记录 0.2.0 这一轮。0.1.0 的 tag 和 ZIP 没有替换。

## 这一版改了什么

仍然免费、无敌，不消耗电池、弹药或药品。医疗仍只处理已有生物肢体的外伤出血、皮肤和肌肉。不补血，不处理器官、骨骼、断肢或内伤。

- 开火前用弹丸的散布、半径和碰撞层检查弹道。主角或旁人已经在弹道上时停火，并换到侧翼。已经飞出的弹丸仍会命中挡路的人。
- 治疗落点按工具距离选取，不再被巡航间距挡掉。全血出血达到 1、失去意识或按 F8 后会持续治疗，降到 0.15 以下才退出，避免在门槛附近来回开火。轻伤不会贴脸。
- 找不到开阔落点时收起等待，落点出现后才回到空中，不钻进墙。主人被传到远处时，也只落到空闲格子上。
- 开阔处巡航大约 6–9 格。左上角常驻图标分开显示护航／停火和当前动作。旋翼、射击、治疗和部署有音量配置。
- 控制器离开背包会说明原因并收回无人机。世界上已经有控制器时不重复发放；控制器真正消失约 3 秒后只补一只。
- 敌对选择仍限于近处的 SpiderHandler、CaveTicks、LaserDroneScript，以及近处且能看见主人的 GuardScript、TurretScript、CeilingTurret。这一轮只实际生成了 wallbiter。

## 怎么测的
