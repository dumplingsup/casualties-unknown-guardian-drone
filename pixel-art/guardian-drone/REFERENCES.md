# Guardian Drone visual source

Original 64×40 pixel art authored by the editable `build.py`, with a 9-color hard palette,
top-left lighting, hard alpha, separate rotor / body / sensor / gimbal layers and 16 pixels per world unit.

Reference study, 2026-11-15:

- [CraftPix / Free Game Assets — Free Drones Asset Pack](https://free-game-assets.itch.io/free-drones-pack-pixel-art): broad horizontal flight silhouette, visibly separate lift assembly and hanging payload, short readable sensor animation.
- [Elthen — 2D Pixel Art Robotic Drone Sprites](https://elthen.itch.io/2d-pixel-art-robotic-drone-sprites): distinct dark lens, strong light armor vs dark underside, compact hanging tool and restrained idle motion.
- [Papoy Core — Free Drone](https://papoycore.itch.io/free-drone): additional authored sprite examples surveyed.

Only visual principles were studied. No third-party sprites, sample frames, textures or
promotional images are embedded or redistributed. Reference previews, if retained locally,
are under gitignored `runs/drone-assessment-20261115/reference-only/`.

The initial 32×24 sprite proved too ambiguous at actual game size. The revision uses four
visible motor positions, long rotor blades, structural arms, an ivory central pod,
landing skids, a medical marking and a separate barrel. Final review remains subject
to the player's assessment in the real game.
